# German (de) – translator notes

- **du, not Sie.** The brief asks for confident, warm, slightly bold copy aimed at developers, makers and creators; German open-source, maker and consumer-tech brands (and the launch/sign-up context) overwhelmingly use *du*. *Sie* would make the hero and form read like a bank. Standards/government readers will accept *du* on a launch page; switch to *Sie* only if the spec/press pages need a formal register. Headings avoid direct address where possible ("Früh dabei. Den Standard mitgestalten."), so a later switch is cheap.
- **Units**: der Gong / die Gongs, das Kè / die Kè (invariant), der Beat / die Beats, der Tick / die Ticks – capitalised everywhere in running text, compounds hyphenated per German rules (*100-Kè-Kreis*, *Kè-Koordinaten*, *Nu:Time-Tick*).
- **Format string kept verbatim**: `gong:beat:tick` in `how.lead` stays lowercase, treated like `hh:mm:ss` (brief: never alter these patterns).
- **"universal Nu:Time" → "Nu:Time-Weltzeit"** (clock label, day bar, points). *Weltzeit* is the established German word for universal time (UT/UTC = „koordinierte Weltzeit"), so it reads natively and signals "one shared clock". *Universelle Nu:Time* sounds translated. Minor risk: a *Weltzeituhr* (e.g. Alexanderplatz) shows many zones – the opposite idea – but context makes it clear.
- **Brand compounds**: *der Nu:Time-Standard · 刻时 Ke-Shi*, *Nu:Time-Uhr*, *Nu:Time-Anzeige* (German Durchkopplung). Nu:Time itself is treated as feminine when needed (die Zeit). *Nu:Time Certified* is kept as an English mark name; *"Nu:Time compatible"* is localised as „Nu:Time-kompatibel" since it is a descriptive claim, not a mark – confirm with legal.
- **Gender-inclusive language**: avoided both the generic masculine and contested forms (Entwickler:innen) by using activity nouns. Form roles are fields, not people (*Softwareentwicklung, Forschung / Wissenschaft, Normung / Verwaltung…*), with the label "Was beschreibt dich am besten?" instead of "Ich bin …". Nav "Developers" → "Entwicklung". Only the compound *Entwicklerdoku* remains (generic compounds are widely accepted).
- **Structural blocker – `n` fields**: the checker forces `n` values to stay byte-identical, so German readers will see **"1,000" and "100,000"** in the "how" cards (in German a comma is the decimal mark, so "1,000" reads as *one point zero*), and **"Longitude" / "Latitude" / "1 kè"** in the kè facts (should be *Längengrad / Breitengrad / 1 Kè*). Recommend making these translatable or formatting the numbers via `Intl.NumberFormat`.
- **Tables**: numbers kept exactly as in English per the brief; only the unit is capitalised (*16.67 Kè*). German would normally write *16,67 Kè* and *2.985.984* – the quartz table and kè tables therefore show English separators. Acceptable in a technical table, but locale-aware formatting would be better.
- **Running-text numbers** use DE/AT style (1.000, 100.000, 86.400). Swiss readers use 1'000 but read the dot form without problems.
- **"AM und PM"** kept in the eliminates list: DACH uses the 24-hour clock, so AM/PM is exactly the thing Germans "never understood" – it still lands as a joke. "24 Stunden" is less of a pain point for German readers but kept for fidelity.
- **"Your place in the sun"** → „Deine Sonne, dein Ort". Avoided *Platz an der Sonne*: idiomatic, but it is also Bülow's 1897 colonial slogan.
- **Puns rebuilt, not translated**: "It's time." → „Es wird Zeit."; "That's how we know the time is now." → „Darum ist jetzt der richtige Moment."; "Not a new idea. It's a finished one." → „Keine neue Idee. Eine zu Ende gedachte."; "Open. Build one." → „Offen. Zum Selberbauen."; "A new era of geometry/trigonometry" → „Geometrie/Trigonometrie für eine neue Zeit."
- **Unclear English**: "The world's next standards are being re-written in 2035" is ambiguous (in 2035 vs by 2035) – rendered as „Die Standards von morgen entstehen bis 2035". "short enough for a meeting" (beat) reworked to „kurz genug für jeden Termin". `time.lead` repeats "it doesn't change the time" – dropped the repetition.
- **Terms**: Solar noon → *Sonnenmittag* (understandable; astronomers say *wahrer Mittag*); radians → *Bogenmaß*, degrees → *Gradmaß* (school terms); "civil time" → *amtliche Zeit*; DST → *Sommerzeit* / *Zeitumstellung* (the word the EU debate used in DACH). National Time Service Center kept as its English proper name.
- **Cities**: German exonyms – Peking, Kairo, Kapstadt, Hongkong, Mexiko-Stadt, Moskau, Riad, Rom, Singapur, Taipeh, Tokio, Karatschi (Duden; *Karachi* is also common), Bogotá/Reykjavík/São Paulo with diacritics. "Santiago" expanded to *Santiago de Chile* (the usual German name; plain "Santiago" is ambiguous). "New York City" → *New York*.
- **Legal text** (`build.license`, `footer.rights`): "Royalty-free patent pledge" → „Gebührenfreie Patentzusage"; trademark sentence translated faithfully – recommend a quick legal review before launch.
