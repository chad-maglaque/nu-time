# French (fr) — translator notes

- **Units**: gong, kè, beat, tic per the glossary; all masculine (le gong, le kè, le beat, le tic). Plurals: gongs, beats, tics; **kè is invariable** (100 kè). Lowercase in running text (the English "Kè" capitals in `how.cards[3]` were not carried over); `geometry.keLabel` stays "Kè" as a field label.
- **"Nu:Time" gender**: treated as masculine (implied *le standard*), e.g. "Nu:Time s'aligne… il n'aura plus jamais besoin…". Where gender would show awkwardly I wrote "l'heure Nu:Time".
- **"universal Nu:Time"** → **"heure universelle Nu:Time"**. Not "temps universel", which in French is the technical name of UT/UT1 and would invite confusion.
- **Standard** → "standard" (lowercase in running text: "le standard Nu:Time", "standard ouvert"), not "norme". *Norme* suggests a formal ISO/AFNOR norm, which Nu:Time is not yet. I did use *normes* / *normalisation* for the official bodies (why[5], roadmap 2027).
- **Prime Meridian** → "méridien d'origine, à Greenwich" on first mention (hero dial hint), then "méridien de Greenwich". There's a nice French irony here (Paris kept its own meridian until 1911), but I did not add it to the copy.
- **1793 card**: the title is "La Révolution décimale", with the capital R doing double duty. The closing line "l'heure décimale avait simplement un temps d'avance" ("decimal time was simply one step ahead") swaps "just too early" for a proud pun on *temps*. The facts are unchanged.
- **AM/PM**: France, Belgium, Switzerland and most of Francophone Africa use the 24-hour clock, so "AM and PM" as something you "never understood" would ring false. I rendered it as "le AM et le PM des anglophones", which is wry and still accurate. Québec readers do meet AM/PM, so it works for them too.
- **eliminates block**: "Nu:Time eliminates." became "Nu:Time fait table rase." ("Nu:Time wipes the slate clean"), followed by "Adieu à tout ce que…". A literal "Nu:Time élimine." reads like a cleaning-product ad.
- **time.lead**: the English says "it doesn't change the time" twice. I said it once.
- **Wordplay**: the English "That's how we know the time is now" became "Voilà comment nous savons que l'heure est venue" ("that's how we know the hour has come"), and "It's time." became "Il est temps." Both land naturally in French.
- **Numbers**: running text uses French conventions with a narrow non-breaking space (1 000, 100 000, 86 400). The `n` fields ("1,000", "100,000") and all table cells (16.67 kè, quartz figures) keep English formatting, as the brief and checker require. **Front-end issue**: French readers will see "1,000" in the how-it-works cards and decimal points in the tables. Consider formatting those with `Intl.NumberFormat` at render time.
- **Typography**: France convention throughout. U+00A0 before ":" and inside « », U+202F (narrow non-breaking space) before ; ! ?. Québec typesetting omits the space before ; ! ?. One shared fr file can't serve both, so I chose France.
- **Join form**: role options are gender-neutral activity nouns ("Développement", "Recherche / université", "Simple curiosité…") under the label "Votre profil". This avoids both masculine-only labels and écriture inclusive (points médians), which is divisive in France. "E-mail" rather than "Courriel" (Québec/official). Swap it if Québec is the priority.
- **Uncertain / for legal review**: "Royalty-free patent pledge" → "Engagement de licence de brevets sans redevance". "Nu:Time Certified" was kept in English as a mark name. If a French mark is wanted, "certifié Nu:Time" is the natural form. "National Time Service Center" → "Centre national du service du temps (NTSC)". That's descriptive, not an official French name.
- **Cities**: current French exonyms: Pékin, Bombay (the AFP/Le Monde usage; "Mumbai" is also common), Le Caire, Le Cap, Mexico, Riyad, Ushuaïa, São Paulo. "Washington D.C." → "Washington" and "New York City" → "New York", as French usage normally drops the qualifiers.
