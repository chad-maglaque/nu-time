# Hindi (hi) — translator notes

- **kè**: kept in Latin script everywhere (`100 kè`, `kè (刻)`, `kè में`), never के. Treated as masculine (like घंटा/मिनट), so "1 kè = दिन का 1/100". Hindi postpositions sit after it with a space (`kè में`, `kè पर`), so the eye can't confuse it with के. I did not propose a Devanagari alternative: every candidate (के, कै, क़े) either collides with the postposition or reads as a different word.
- **Other units**: गोंग (m.), बीट (f.), टिक (f.), as the glossary says. Hindi doesn't add a plural ending to loanword units after a number ("10 गोंग, 1,000 बीट"), so `gongs/beats/ticks` = the singular forms. The historical Chinese term in the heritage card and licence stays **gēng (更)** in Latin, so it stays separate from the unit गोंग.
- **"Universal Nu:Time" / "universal time"** → **वैश्विक** (global). It's the everyday modern word. सार्वभौमिक is heavier, and "यूनिवर्सल" is Hinglish.
- **Standard / open standard** → **मानक / खुला मानक**. Indian readers know मानक from BIS (भारतीय मानक ब्यूरो). "ओपन" is kept only where it is the term of art: ओपन हार्डवेयर, ओपन लाइसेंस. "Nu:Time Certified" and "Nu:Time compatible" are left in English as mark/label names.
- **Common tech and everyday loans in Devanagari**: टाइम ज़ोन, लीप सेकंड, डेलाइट सेविंग, डेवलपर, API, स्पेसिफ़िकेशन, रेफ़रेंस, इम्प्लीमेंटेशन, सैटेलाइट. **Geography and maths** use school (NCERT) Hindi, which every reader knows: अक्षांश, देशांतर, भूमध्य रेखा, अंतरराष्ट्रीय तिथि रेखा, समकोण, समबाहु त्रिभुज, सम पंचभुज, अंतःकोण, 10 की घात, आवर्तकाल. Nuktas are used consistently (ज़ोन, फ़्रांस, ख़त्म).
- **Prime Meridian** → "ग्रीनविच की प्राइम मेरिडियन". It is glossed once as "(शून्य देशांतर रेखा)" in the dial hint. The textbook term प्रमुख याम्योत्तर is too Sanskritised for this site.
- **Numbers**: running text uses Indian grouping (**1,00,000 टिक**). The `how.cards[2].n` value has to stay "100,000" (the checker enforces it), so the card and the hero text group the same number differently. Table values (quartz, trig, geometry) are untouched.
- **Checker constraint, please review**: `ke.facts[].n` holds the words "Longitude"/"Latitude", and the checker requires `n` to be byte-identical. So those two labels show **in English** on the Hindi page. As a workaround, each `text` starts with देशांतर: / अक्षांश:. Suggest exempting non-numeric `n` values or moving these labels to a separate key.
- **`gong:beat:tick` in `how.lead`**: kept verbatim per the brief, then glossed as "यानी गोंग:बीट:टिक".
- **Compass letters**: E/W/N/S → पू / प / उ / द, the abbreviations used on Hindi maps. They render in the clock as e.g. "12.3 kè उ". If that looks too terse in the UI, use पूर्व/पश्चिम/उत्तर/दक्षिण.
- **Puns**: "It's time." → "अब वक़्त आ गया है।" and "That's how we know the time is now." → "इसीलिए हम कहते हैं: वक़्त अभी है।" The second one uses वक़्त (moment, opportunity) against समय (clock time). "Decimal time was just too early" → "बस अपने समय से पहले आ गया था" keeps the double meaning.
- **Night watches** → **पहर**. Indian readers know पहर from their own tradition, so the Chinese "five watches" lands without explanation.
- **Daylight saving**: India has never used it, so many readers won't know what it is. The "why" card works the explanation in naturally ("साल में दो बार घड़ियाँ आगे-पीछे होती हैं…"). The eliminates list keeps the bare term.
- **SOV ordering**: "Nu:Time eliminates. → [list] → and keeps only…" is rendered as heading "Nu:Time हटा देता है।" + list + "और रखता है सिर्फ़ वही…". That works if the three pieces display in that order. If the layout reorders them, the Hindi will read oddly.
- **Audience sensitivity (flag, not changed)**: the China-standards card ("2035") is translated faithfully and neutrally. Indian readers may react coolly to a China-leadership framing. India's own NavIC system and IST debate (e.g. demands for a separate North-East time zone) would resonate strongly if the team ever wants an India-specific heritage/why card (e.g. ghaṭī/muhūrta, historical Calcutta/Bombay time). I added none of this.
- **Minor source nits**: English mixes "Kè"/"kè" in `how.cards[3]`. Hindi uses lowercase kè throughout. `time.lead` repeats "it doesn't change the time", and Hindi drops the repetition.
