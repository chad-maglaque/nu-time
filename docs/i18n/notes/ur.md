# Urdu (ur) translation notes

- **kè stays Latin everywhere** (`kè`, unchanged in singular and plural). Every Urdu-script spelling (کے، کہ، کی) is already a high-frequency function word, so no clean alternative exists. I also wrote around **spoken** collisions: `kè` is never directly followed by کے/کی/کا (e.g. "100 kè والا دائرہ", not "100 kè کا دائرہ"), because read aloud "kè ke" is just as ambiguous as writing کے.
- **Glossary units:** گونگ / بیٹ / ٹک, uninflected in the plural ("10 گونگ"), which is how Urdu treats English unit loans (cf. "10 کلومیٹر"). Readout pattern in body text is written گونگ:بیٹ:ٹک, which renders gong-first in RTL.
- **Bidi and parentheses (important for review):** a bracket that opens after Latin/CJK text and closes before Urdu text gets split directions and renders broken in an RTL paragraph. So I avoided the glossary form `Ke-Shi (刻时)` and kept the source order `刻时 Ke-Shi` with no brackets, and wrote `kè · 刻` / `更 gēng` / "kè یعنی 刻" instead of `kè (刻)` / `gēng (更)`. Brackets are used only when an Urdu word comes before them, e.g. "(خودکار)", "(اختیاری)".
- **gēng:** kept in Latin as `更 gēng`, not Urdu script: گینگ reads as English "gang", and گنگ means "mute". The Chinese night watches are given as پہر, the matching South Asian unit, which every reader knows ("رات پانچ پہروں میں بٹی ہوتی تھی").
- **"universal Nu:Time" = عالمی Nu:Time.** عالمی is the everyday word for "global/universal" in both countries. "Standard" as a proper name = Nu:Time اسٹینڈرڈ. "Open standard" = اوپن اسٹینڈرڈ, as tech readers actually say it. Generic "standards" (bodies, international) = معیارات.
- **Register:** everyday loans where those are what people say (ٹائم زون، ڈے لائٹ سیونگ، لیپ سیکنڈ، ڈیولپر، ڈیوائس، ٹرگنومیٹری). Settled school terms where they exist (عرض بلد، طول بلد، خط استوا، قائمہ زاویہ، مساوی الاضلاع مثلث، طلوعِ آفتاب). I avoided Persianised coinages such as خطِ نصف النہار اول for the Prime Meridian and used پرائم میریڈین.
- **Digits:** Western digits (0–9) throughout, to match the clock readout, the tables and the `n` fields. Pakistani and Indian Urdu web/tech text commonly uses them. Switching to Urdu numerals ۰–۹ would be a site-wide decision.
- **Number grouping:** running text uses lakh grouping (1,00,000), which is natural in both countries. The `how.cards[2].n` field must stay `100,000` (the validator checks it), so the card and the hero copy group the same number differently. That is acceptable, but a reviewer may want to align them.
- **`ke.facts[2..3].n` = "Longitude"/"Latitude" must stay English** (the validator requires `n` to be unchanged), so English words appear as card headings on an Urdu page. To compensate, I began each card's text with طول بلد: / عرض بلد:. Recommend that `n` be made translatable for these two cards.
- **"Nu:Time eliminates." + "the things you never understood…"** relies on English word order (verb, then object). Urdu is verb-final, so the heading is "Nu:Time ختم کر دیتا ہے…" with an ellipsis that runs into the list. It works, but it is the least natural spot on the page. An alternative heading would be "Nu:Time کے بعد نہیں رہیں گے…".
- **Puns:** "It's time." → "اب وقت آ گیا ہے۔" (the pun works in Urdu). "That's how we know the time is now." → "اسی لیے ہم کہتے ہیں: وقت یہی ہے۔". "Your place in the sun" → "سورج تلے آپ کی جگہ".
- **Small tidy-ups:** `time.lead` repeats "it doesn't change the time", and I dropped the repeat. The form label "I am a…" can't precede a noun in Urdu (SOV), so it became "آپ کون ہیں؟". "Nu:Time Certified" stays as the Latin mark name. The phrase "Nu:Time compatible" in `build.cert` is also left in English, in quotes, because it reads as a claim/mark. Please confirm or replace it with “Nu:Time سے ہم آہنگ”.
- **Neutrality:** India is بھارت, the form used officially in both countries. Tel Aviv = تل ابیب and Taipei = تائپے, the standard Urdu exonyms with no added framing. BeiDou = بیدو نیویگیشن نظام.
- **Heritage order:** `build.mjs` leads ur with the `in` card, which doesn't exist yet, so Urdu readers see China first. A South Asian card would land well here. For example, the گھڑی was historically a unit of 1/60 day (24 minutes), and the پہر was 1/8 day. That is content for the English source, not something I added.
- **Uncertain:** فیز ایکیومولیٹر (no settled Urdu term; transliterated). "Regular pentagon" = باقاعدہ مخمس (the textbook term منتظم مخمس is less widely known). سرکاری وقت for "civil time".
