# zh (简体中文) — translator notes

- **Brand.** Every section leads with 刻时 and pairs it as **刻时 Nu:Time** (the checker also requires `Nu:Time` in every string whose English contains it). Within one string, later mentions use 刻时 alone. "Ke-Shi" is just the romanisation of 刻时, so in Chinese prose it is dropped where it only glossed the brand (meta, hero eyebrow, heritage card). It stays in the legal lines and in the standards card ("刻时 Ke-Shi").
- **brandLocal conflict (needs a decision).** BRIEF says `brandLocal` = `刻时`, but `tests/check_locales.py` fails unless the value contains `Nu:Time`, because the English is `Nu:Time`. I set it to `刻时 Nu:Time` so the check passes. Nothing in the repo reads `brandLocal` today. If it should be exactly `刻时`, exempt `brandLocal` from the token check.
- **"universal Nu:Time" → 统一刻时.** It is short and works in a UI label, and it follows the familiar 北京时间 / 协调世界时 pattern, where a qualifier comes before 时. 全球统一的 Nu:Time is too long for the clock label and day bar. Where the token is required, it appears as 统一刻时 Nu:Time. "Universal time" (the feature card) is 全球同一时间, to avoid 世界时, which already means UT.
- **"time and location reimagined." → 时间与位置，重新定义。** The topic–comment structure reads as native Chinese, unlike the calque 重新想象. 重新定义 is confident without being 颠覆-style hype. 位置 is used rather than 方位 (direction) or 地点, because the site means your position on Earth. The same line is used for the hero, the footer tagline and the meta title, and it echoes 时间，重新定义 in the next section.
- **"Nu:Time eliminates." → 刻时 Nu:Time，一笔勾销。** The heading uses an idiom ("struck out with one stroke of the pen"), then the list follows as 那些你本来就没真正搞懂的东西：… The base-60 items are rendered as 每小时 60 分钟、每分钟 60 秒, so readers don't think Nu:Time drops the *word* 秒, which it reuses.
- **Units.** 更 / 刻 / 分 / 秒 per the glossary. On the unit cards, pinyin is added (更 · gēng etc.), because 更 is otherwise read gèng ("more"). how.lead gives 更:分:秒 followed by (gong:beat:tick), keeping the pattern intact. Where a sentence is about SI time (铯原子钟, 国际单位制"秒", 86400 个原子秒, 闰秒), the context marks it as SI. No 刻时分/刻时秒 qualifier was needed.
- **Table values.** The numbers are untouched. The unit `kè` in geometry/trig cells is written 刻 (`100 刻`), as the glossary and checker allow. **ke.facts `n` must stay verbatim**, so "1 kè", "Longitude" and "Latitude" render in English on the zh page. I added 经度：/纬度： to the matching `text` so the cards still make sense. Ideally those `n` labels would be translatable.
- **Heritage (China card, lead).** It uses 百刻制, 漏刻, 五更, with claims no stronger than the English ("两千多年来", era "古代至 17 世纪"). The title is 百刻制（刻）. The section title, "Not a new idea. It's a finished one.", is rendered as 不是新想法，是集大成, because a literal "finished idea" doesn't land in Chinese.
- **Time-zones card (neutrality).** 中国幅员辽阔，地理上横跨约五个时区，全国统一使用北京时间 is stated as geography, with no evaluation. The title "politics, not physics" is softened to 时区是人为约定，不是自然规律, because a literal 政治 next to the China line would read as a criticism of 北京时间. Nu:Time is framed as complementing the shared time (大家共用一个时间，各地照样看得清自己的太阳).
- **Standards card.** It says 提出要…发挥引领作用 (factual; no claim of endorsement). The ending 献给这项事业，也献给每一个人 makes it clear that Nu:Time is offered *to* the work. 位于西安的 was added before 国家授时中心, per the BRIEF hint. Remove it if additions should be zero.
- **Spain card.** The title is 时钟与太阳错位的国家 (factual) rather than "the wrong time zone", which reads as a judgement in Chinese.
- **Awkward English.** Some English lines needed adjusting:
  - time.lead says "doesn't change the time" twice. The redundancy is dropped.
  - "being re-written in 2035" is ambiguous. It is rendered as 2035：世界的下一代标准正在改写.
  - "That's how we know the time is now" becomes 正因如此，我们知道：时候到了.
  - "Machines already count in tens" is literally false (binary), so it became 机器本来就习惯十进制.
- **Numbers.** Running text uses 1000 and 10 万 (natural Chinese), while table/quartz values keep their English commas. There is a half-width space between Hanzi and Latin/digits throughout, and full-width punctuation with “” quotes. The text addresses the reader as 你 (creator register), including on the form.
- **Cities.** Standard mainland exonyms. Washington D.C. → 华盛顿 and New York City → 纽约. Hong Kong / Taipei are plain city names (香港 / 台北), with nothing added.
- **Uncertain.** I'm not sure about 统一刻时 vs 全球刻时. 统一 can be parsed as a verb in isolation, but it is fine in context. "haptic pulse every kè" → 每过一刻轻震一次 is colloquial; use 触感脉冲 if a more technical tone is preferred.
