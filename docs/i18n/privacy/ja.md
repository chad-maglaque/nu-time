# プライバシーポリシー

**データ管理者：** Nu-Time Inc. · **連絡先：** privacy@nu-time.org · **更新日：** 2026-11-20

Nu:Timeのメーリングリストに登録されると、当社はフォームに入力された内容（メールアドレス、および任意でお名前、立場、国・地域、メッセージ）に加えて、ブラウザの言語とタイムゾーン、登録に使われたページ、そしてホスティング事業者が接続情報から推定した国を収集します。Nu:Timeに関するお知らせは、フォームのチェックボックスにチェックを入れた方にのみメールでお送りします。それ以外の場合、これらの情報は、この標準にどのような方が関心を持っているかの把握と、メッセージへの返信にのみ使用します。情報は、配信停止または削除のご依頼があるまで保管します。販売することも、広告目的で共有することもありません。

データは当社のホスティング事業者（Vercel、およびデータベースを提供するUpstash）に保存され、米国またはその他の国で処理される場合があります。フォームを送信することで、この移転に同意したものとみなされます。中国本土にお住まいの場合、この同意には個人情報の中国国外への移転も含まれます。スパム対策として、フォームはIPアドレスに結びついたカウンターを1時間だけ保持します。また、一般的なウェブサイトと同様に、ホスティング事業者がサイトの運営と保護のため、IPアドレスを含む短期間のアクセスログを保管します。

時計がブラウザに位置情報を求めるのは、「現在地（自動検出）」または「現在地を使う」を選んだ場合だけです。ブラウザが位置情報を提供できない、または提供しない場合、時計はホスティング事業者に、接続情報から推定したおおよその位置（通常は最寄りの都市）を問い合わせます。いずれの場合も、位置情報はブラウザ内で太陽の位置を求めるためだけに使われます。選んだ場所と言語はブラウザに記憶され、次回も同じ場所で時計が開きます。これらが当社に送信されることはありません。このサイトはCookie、アクセス解析、トラッカーを使用していません。

配信の停止は、どのメールからでもいつでも行えます。また、privacy@nu-time.orgまでご連絡いただければ、ご自身のデータの開示・訂正・削除を求めることができます。これらの権利は、お住まいの国・地域にかかわらずすべての方に適用され、GDPR、UK GDPR、PIPLの要件を満たしています。また、お住まいの国・地域のデータ保護機関に苦情を申し立てることもできます。
