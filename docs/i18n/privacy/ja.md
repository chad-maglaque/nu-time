# プライバシーポリシー

**データ管理者：** Nu-Time Inc. · **連絡先：** privacy@nu-time.com · **更新日：** 2026-11-17

Nu:Timeのメーリングリストに登録されると、当社はフォームに入力された内容（メールアドレス、および任意でお名前、立場、国・地域、メッセージ）に加えて、ブラウザの言語とタイムゾーン、登録に使われたページ、そしてホスティング事業者が接続情報から推定した国を収集します。これらの情報は、Nu:Timeに関するお知らせの送信と、この標準にどのような方が関心を持っているかの把握にのみ使用します。販売することも、広告目的で共有することもありません。

データは当社のホスティング事業者（Vercel、およびデータベースを提供するUpstash）に保存され、米国またはその他の国で処理される場合があります。フォームを送信することで、この移転に同意したものとみなされます。中国本土にお住まいの場合、この同意には個人情報の中国国外への移転も含まれます。

時計がブラウザに位置情報を求めるのは、「現在地（自動検出）」または「現在地を使う」を選んだ場合だけです。ブラウザが位置情報を提供できない、または提供しない場合、時計はホスティング事業者に、接続情報から推定したおおよその位置（通常は最寄りの都市）を問い合わせます。いずれの場合も、位置情報はブラウザ内で太陽の位置を求めるためだけに使われ、保存されることも当社に送信されることもありません。

配信の停止は、どのメールからでもいつでも行えます。また、privacy@nu-time.comまでご連絡いただければ、ご自身のデータの開示・訂正・削除を求めることができます。EU、英国、中国にお住まいの方は、GDPR、UK GDPR、PIPLに基づく追加の権利を有しており、当社はこれを尊重します。
