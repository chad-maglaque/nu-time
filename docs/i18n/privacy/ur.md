جب آپ Nu:Time کی فہرست میں شامل ہوتے ہیں تو ہم وہ معلومات جمع کرتے ہیں جو آپ فارم میں لکھتے ہیں، یعنی ای میل، اور اگر آپ چاہیں تو نام، کردار، ملک اور پیغام۔ اس کے ساتھ ہم آپ کے براؤزر کی زبان اور ٹائم زون، وہ صفحہ جہاں سے آپ نے سائن اپ کیا، اور وہ ملک بھی جمع کرتے ہیں جس کا تعین ہمارا ہوسٹ آپ کے کنکشن سے کرتا ہے۔ ہم آپ کو Nu:Time کی خبریں ای میل سے صرف اسی صورت میں بھیجتے ہیں جب آپ فارم میں باکس پر نشان لگائیں؛ ورنہ ہم یہ معلومات صرف یہ سمجھنے کے لیے کہ اس اسٹینڈرڈ میں کن لوگوں کی دلچسپی ہے، اور آپ کے پیغام کا جواب دینے کے لیے استعمال کرتے ہیں۔ ہم یہ معلومات اس وقت تک رکھتے ہیں جب تک آپ سبسکرپشن ختم نہ کریں یا ہم سے انہیں حذف کرنے کو نہ کہیں۔ ہم یہ معلومات نہ بیچتے ہیں اور نہ اشتہارات کے لیے کسی کے ساتھ شیئر کرتے ہیں۔

یہ ڈیٹا ہمارے ہوسٹنگ فراہم کنندگان کے پاس ذخیرہ کیا جاتا ہے، یعنی Vercel کے پاس، اور ڈیٹا بیس کے لیے Upstash کے پاس۔ یہ فراہم کنندگان اسے امریکہ یا دوسرے ممالک میں پراسیس کر سکتے ہیں۔ فارم جمع کر کے آپ اس منتقلی پر رضامندی دیتے ہیں۔ اگر آپ مین لینڈ چین میں ہیں تو اس رضامندی میں آپ کی ذاتی معلومات کی چین سے باہر منتقلی بھی شامل ہے۔

گھڑی آپ کے براؤزر سے آپ کا مقام صرف اسی صورت میں مانگتی ہے جب آپ "موجودہ مقام (خودکار)" یا "میرا مقام استعمال کریں" منتخب کریں۔ اگر براؤزر مقام نہ بتا سکے یا نہ بتائے تو گھڑی ہمارے ہوسٹ سے اندازاً مقام مانگتی ہے، جو عموماً قریب ترین شہر ہوتا ہے اور جس کا تعین ہوسٹ آپ کے کنکشن سے کرتا ہے۔ دونوں صورتوں میں مقام صرف آپ کے براؤزر کے اندر سورج کی جگہ طے کرنے کے لیے استعمال ہوتا ہے؛ اسے نہ ذخیرہ کیا جاتا ہے اور نہ ہمیں بھیجا جاتا ہے۔
