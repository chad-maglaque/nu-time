# رازداری

**ڈیٹا کنٹرولر:** Nu-Time Inc.‎ · **رابطہ:** privacy@nu-time.org · **تازہ کاری:** ‎2026-11-17

جب آپ Nu:Time کی فہرست میں شامل ہوتے ہیں تو ہم وہ معلومات جمع کرتے ہیں جو آپ فارم میں لکھتے ہیں، یعنی ای میل، اور اگر آپ چاہیں تو نام، کردار، ملک اور پیغام۔ اس کے ساتھ ہم آپ کے براؤزر کی زبان اور ٹائم زون، وہ صفحہ جہاں سے آپ نے سائن اپ کیا، اور وہ ملک بھی جمع کرتے ہیں جس کا تعین ہمارا ہوسٹ آپ کے کنکشن سے کرتا ہے۔ ہم یہ معلومات صرف آپ کو Nu:Time کی خبریں بھیجنے اور یہ سمجھنے کے لیے استعمال کرتے ہیں کہ اس اسٹینڈرڈ میں کن لوگوں کی دلچسپی ہے۔ ہم یہ معلومات نہ بیچتے ہیں اور نہ اشتہارات کے لیے کسی کے ساتھ شیئر کرتے ہیں۔

یہ ڈیٹا ہمارے ہوسٹنگ فراہم کنندگان کے پاس ذخیرہ کیا جاتا ہے، یعنی Vercel کے پاس، اور ڈیٹا بیس کے لیے Upstash کے پاس۔ یہ فراہم کنندگان اسے امریکہ یا دوسرے ممالک میں پراسیس کر سکتے ہیں۔ فارم جمع کر کے آپ اس منتقلی پر رضامندی دیتے ہیں۔ اگر آپ مین لینڈ چین میں ہیں تو اس رضامندی میں آپ کی ذاتی معلومات کی چین سے باہر منتقلی بھی شامل ہے۔

گھڑی آپ کے براؤزر سے آپ کا مقام صرف اسی صورت میں مانگتی ہے جب آپ "موجودہ مقام (خودکار)" یا "میرا مقام استعمال کریں" منتخب کریں۔ اگر براؤزر مقام نہ بتا سکے یا نہ بتائے تو گھڑی ہمارے ہوسٹ سے اندازاً مقام مانگتی ہے، جو عموماً قریب ترین شہر ہوتا ہے اور جس کا تعین ہوسٹ آپ کے کنکشن سے کرتا ہے۔ دونوں صورتوں میں مقام صرف آپ کے براؤزر کے اندر سورج کی جگہ طے کرنے کے لیے استعمال ہوتا ہے؛ اسے نہ ذخیرہ کیا جاتا ہے اور نہ ہمیں بھیجا جاتا ہے۔

آپ کسی بھی ای میل کے ذریعے کسی بھی وقت سبسکرپشن ختم کر سکتے ہیں۔ آپ privacy@nu-time.org پر لکھ کر ہم سے اپنا ڈیٹا دیکھنے، درست کرنے یا حذف کرنے کی درخواست بھی کر سکتے ہیں۔ یورپی یونین کے رہائشیوں کو GDPR کے تحت، برطانیہ کے رہائشیوں کو UK GDPR کے تحت اور چین کے رہائشیوں کو PIPL کے تحت اضافی حقوق حاصل ہیں، اور ہم ان حقوق کا احترام کرتے ہیں۔
