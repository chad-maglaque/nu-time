# 隐私政策

**个人信息处理者：** Nu-Time Inc. · **联系方式：** privacy@nu-time.org · **更新日期：** 2026-11-20

当您加入刻时 Nu:Time 邮件列表时，我们会收集您在表单中填写的内容（邮箱，以及选填的姓名、身份、国家和留言），以及您的浏览器语言和时区、您提交订阅时所在的页面，以及我们的托管服务商根据您的网络连接推断出的国家。只有在您勾选表单中的复选框后，我们才会通过邮件向您发送刻时资讯；否则，我们仅将这些信息用于了解哪些人对该标准感兴趣，以及回复您的留言。我们会保存这些信息，直至您退订或要求我们删除。我们不会出售这些信息，也不会为广告目的共享这些信息。

上述数据存储在我们的托管服务商处（Vercel，以及提供数据库服务的 Upstash），它们可能在美国或其他国家处理这些数据。提交表单即表示您同意上述传输；如您位于中国大陆，该同意包括将您的个人信息向中国境外提供。为防止垃圾信息，表单会将与您 IP 地址关联的计数保留一小时。与所有网站一样，我们的托管服务商也会保留短期访问日志（包括 IP 地址），用于网站的运行和安全防护。

只有当您选择“当前位置（自动检测）”或点击“使用我的位置”时，时钟才会向您的浏览器请求您的位置。如果浏览器无法或不提供位置，时钟会向我们的托管服务商获取其根据您的网络连接推断出的大致位置（通常为最近的城市）。无论哪种情况，位置信息仅在您的浏览器中用于确定太阳的位置。您的浏览器会记住您选择的地点和语言，以便下次打开时钟时保持原样；这些信息都不会发送给我们。本网站不使用 Cookie、统计分析工具或追踪器。

您可以随时通过任意一封邮件退订，也可以发送邮件至 privacy@nu-time.org，要求查阅、更正或删除您的数据。无论您身在何处，这些权利对所有人一视同仁，并符合《通用数据保护条例》（GDPR）、英国《通用数据保护条例》（UK GDPR）和《个人信息保护法》（PIPL）的要求。您也可以向您所在地的个人信息保护监管机构投诉。
