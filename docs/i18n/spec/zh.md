# 刻时 Nu:Time 标准 v1.0

**状态：** 公开征求意见稿 · **维护方：** Nu-Time Inc. · **许可：** CC BY 4.0 · **更新日期：** 2026-11-17

刻时 Nu:Time™（Ke-Shi™）是一项用于表示时间与位置的开放标准。它规定了一日的十进制划分、全球共用的一座统一时钟，以及时间与地理共享的单一角度单位——**刻**。它以地球本身为基准：一日即地球自转一周，因此刻时永远不需要闰秒。

## 1. 时间单位

| 英文名 | 中文名 | 占一日的比例 | 细分 | 标称时长（国际单位制） |
|---|---|---:|---|---:|
| Day | 日 rì | 1 | 10 更 | 86,400 s |
| **Gong** | 更 gēng | 1/10 | 10 刻 · 100 分 | 8,640 s (2 h 24 min) |
| **Kè** | 刻 kè | 1/100 | 10 分 | 864 s (14.4 min) |
| **Beat** | 分 fēn | 1/1,000 | 100 秒 | 86.4 s |
| **Tick** | 秒 miǎo | 1/100,000 | — | 0.864 s |

- 1 日 = 10 更 = 100 刻 = 1000 分 = 100000 秒。
- **以地球为基准。** 刻时的一日即地球自转一周（平太阳日，以 UT1 计量），每个单位都是一日的精确分数。国际单位制时长均为标称值：由于地球自转有快有慢，实际的 1 刻时秒与 0.864 s 相差约十纳秒。
- 按标称值，国际单位制的 1 秒 = 1.157407… 刻时秒，1 小时 = 41.666… 刻时分。

### 1.1 显示格式

规范显示格式为 **`GG:BB:TT`**：更（00–09）、更内的分（00–99）、分内的秒（00–99）。刻即 `BB` 的十位数字：以 `05:37:50` 为例，按当日计分别为 5 更、53 刻、537 分。

```
ticksOfDay = gong × 10,000 + beatWithinGong × 100 + tickWithinBeat
beatsOfDay = ticksOfDay / 100
keOfDay    = ticksOfDay / 1,000
```

实现**应**截断（向下取整）至当前刻时秒，不应提前进位。

### 1.2 本地化名称

只翻译单位名称，不改动时长和字段顺序。`GG:BB:TT` 在所有语言中完全相同。

| 语言 | 更 | 刻 | 分 | 秒 |
|---|---|---|---|---|
| 英语 | gong | kè | beat | tick |
| 法语 / 西班牙语 / 意大利语 | gong | kè | beat | tic |
| 德语 | Gong | Kè | Beat | Tick |
| 中文 | 更 gēng | 刻 kè | 分 fēn | 秒 miǎo |

`05:37:50` 用中文读作**五更三十七分五十秒**。“更”原指古代夜间的更次，“刻”原指一日的百分之一；“分”“秒”则让每个读数都像“时分秒”一样自然。刻时单位与国际单位制单位同时出现且可能混淆时，写作**刻时分**和**刻时秒**。

## 2. 全球统一同步

- **统一刻时**是默认的规范参照。0 更 `00:00:00` 始于本初子午线上的午夜，即 **00:00:00 UT1**，与 UTC 00:00 相差不超过 0.9 s（约 1 刻时秒）。`05:00:00` 即格林尼治的正午。
- 同一瞬间，地球上各地读到的统一刻时完全相同。刻时不设时区，不设夏令时，也不设日期变更线。
- 存储或传输的每个刻时值都**应**附带其参照（§5）。未注明参照的值即为统一刻时。

### 2.1 不设闰秒

UTC 将一日固定为 86400 个原子秒。地球自转一周的时长并不固定，会有一两毫秒的变化，因此自 1972 年以来，UTC 已插入 27 个闰秒，使其与地球自转的偏差保持在 0.9 s 以内；国际计量界已决定最迟于 2035 年停止插入闰秒，此后民用时间将与太阳渐行渐远。

刻时无秒可闰。它划分的是地球的实际自转，因此日是基本单位，刻时秒由日导出，而不是反过来。刻时将始终与太阳同步。

实现由 **UT1 = UTC + DUT1** 得出统一刻时，其中 DUT1（目前 |DUT1| < 0.9 s）由国际地球自转和参考系服务（IERS）发布。无法获取 DUT1 的设备**可**直接使用 UTC，此时误差约在 1 刻时秒以内。由 UTC 导出刻时的设备，在 UTC 闰秒期间**不应**回跳，而是保持当前刻时秒不变。

### 2.2 以日计数，不设闰年

刻时 v1 规定的是一日之内的时刻。日期**可**写作 **Nu:Day 日序数**，即简化儒略日数（MJD）：从 1858 年 11 月 17 日格林尼治午夜（Nu:Day 0）起连续累计的日数。它不分月、不分周，也没有闰年：2000 年 1 月 1 日为 Nu:Day 51544；2026 年 11 月 17 日为 Nu:Day 61361。完整的刻时时间戳写作 `61361 · 05:37:50`。

凡要让年与季节保持一致的历法，都需要某种置闰规则，因为地球公转一周约为 365.2422 日。这类历法可与刻时并用，不在本标准范围之内。

### 2.3 可选的本地参照

在清楚标注的前提下，设备还**可**显示：

| 参照 | 一日的起点 | 用途 |
|---|---|---|
| `utc`（统一） | 格林尼治午夜 | 规范参照。用于协调、记录和数据交换。 |
| `solar`（平太阳时） | 当地平太阳午夜：统一刻时 + 经度/15 h | “你的太阳”：在你所在的经度，正午 ≈ 05:00:00。 |
| `ke`（按刻取整的太阳时） | 同 `solar`，但经度就近取整到整刻（3.6°） | 以 10 刻时分为步长的区域太阳日。 |
| `civil`（现行民用时） | 当地民用钟表时间的午夜（IANA 时区） | 推广期间的过渡手段。 |

统一值与本地值**不应**在未加说明的情况下混用。

## 3. 刻作为角度单位

一整圈为 **100 刻**：1 刻 = 3.6°，1° = 5/18 刻 ≈ 0.2778 刻。地球每日自转一圈，因此 1 刻经度恰好等于 1 刻时间。

### 3.1 坐标

- **Nu:Long**：以刻表示的经度，向东（正）或向西（负）0–50 刻。50 刻 = 180°。本初子午线（格林尼治）为 0 刻。
- **Nu:Lat**：以刻表示的纬度，向北（正）或向南（负）0–25 刻。25 刻 = 90°。

### 3.2 几何

刻值以小数书写，四舍五入保留两位小数（精确刻值 = 度数 × 100 / 360）。

| 角 | 刻值 | 度数 |
|---|---:|---:|
| 周角（转一整圈） | 100 | 360° |
| 正六边形的内角 | 33.33 | 120° |
| 正五边形的内角 / 外角 | 30 / 20 | 108° / 72° |
| 平角 · 三角形内角和 | 50 | 180° |
| 直角 | 25 | 90° |
| 等边三角形的内角 | 16.67 | 60° |
| 直角的一半 | 12.5 | 45° |
| 直角三角形中的 30° 角 | 8.33 | 30° |

### 3.3 三角函数

三角函数可以直接以刻为自变量：sin 25 刻 = 1，cos 50 刻 = −1，sin 75 刻 = −1，cos 100 刻 = 1。每日重复一次的波，周期恰好为 100 刻。

| 角 | 度数 | sin | cos | tan |
|---|---:|---:|---:|---:|
| 0 刻 | 0° | 0 | 1 | 0 |
| 8.33 刻 | 30° | 1/2 | √3/2 | √3/3 |
| 12.5 刻 | 45° | √2/2 | √2/2 | 1 |
| 16.67 刻 | 60° | √3/2 | 1/2 | √3 |
| 25 刻 | 90° | 1 | 0 | — |
| 50 刻 | 180° | 0 | −1 | 0 |
| 75 刻 | 270° | −1 | 0 | — |
| 100 刻 | 360° | 0 | 1 | 0 |

### 3.4 表盘

刻时指针式表盘不标数字，只有四个等分刻度（0、25、50、75 刻），其中零点加以突出，更、分、秒都在零点归零进位。表盘**宜**按佩戴者的 Nu:Long（就近取整到整刻）旋转：在格林尼治，零点位于正下方；在任何地方，更针都在当地太阳正午时指向正上方。

## 4. 太阳位置

Nu:Long 为向东 *X* 刻处的当地**平**太阳正午，以统一刻时表示为：

```
solarNoon = 05:00:00 − X kè = 500 − 10·X beats   (X negative for west)
```

示例：上海（东经 121.47° = 向东 33.74 刻）→ 约 `01:62:58`；德里（东经 77.21° = 向东 21.45 刻）→ 约 `02:85:53`；纽约（西经 74.01° = 向西 20.56 刻）→ 约 `07:05:57`。

**视**太阳正午（真太阳正午）与平太阳正午之差即时差，全年最大约 ±1.1 刻（±16 min）；显示真实太阳位置的实现**宜**计入时差。日出和日落以太阳位于地平线下 0.833°（0.231 刻）为标准计算，并随日期和 Nu:Lat 而变化；在两极附近，太阳可能终日不升或终日不落。

太阳位置计算**应**使用绝对时刻，不应把十进制时间值误当作 UTC。

## 5. 交换记录：`nu-time/v1`

```json
{
  "schema": "nu-time/v1",
  "instant": "2026-11-17T12:00:00Z",
  "reference": "utc",
  "nuDay": 61361,
  "location": { "nuLat": 8.68, "nuLong": 33.74, "latitude": 31.23, "longitude": 121.47 },
  "ticksOfDay": 50000,
  "gong": 5, "beat": 0, "tick": 0,
  "display": "05:00:00",
  "locale": "en"
}
```

不变式：`0 ≤ gong ≤ 9`；`0 ≤ beat ≤ 99`；`0 ≤ tick ≤ 99`；`ticksOfDay = gong·10000 + beat·100 + tick`；各语言中的单位完全相同；时刻与位置是两个独立的字段。

## 7. 硬件计时

1 刻时秒的标称时长为 0.864 s，因此频率为 *f* Hz 的振荡器每刻时秒需要 *f* × 0.864 个周期。凡能被 125 整除的频率，都可以精确分频。

| 晶振 | 周期数 / 刻时秒 | 分频方式 |
|---|---:|---|
| **3.456 MHz** | **2,985,984** | 精确整数分频——刻时参考晶振 |
| 32.768 kHz | 28,311.552 | 相位累加器，在 28,311 / 28,312 个周期之间交替（每 125 个刻时秒中有 69 个取长周期） |
| 1 / 10 / 16 MHz | 864,000 / 8,640,000 / 13,824,000 | 精确整数分频 |

精度取决于振荡器的 ppm 误差、温度和老化，与分频器无关：20 ppm ≈ 2 刻时秒/日；2 ppm ≈ 0.2 刻时秒/日。设备**宜**通过 GNSS 或 NTP 驯服时钟，并在可获得 DUT1 时加以应用；**不应**以循环休眠 864 ms 的方式推进时间。
